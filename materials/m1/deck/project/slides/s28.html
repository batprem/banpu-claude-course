อะไรคือ “ข้อมูลอ่อนไหว”

ข้อมูลส่วนบุคคล: เลขบัตร เงินเดือน บัญชีธนาคาร สุขภาพ

ข้อมูลการเงิน ที่ยังไม่เปิดเผยต่อสาธารณะ

ความลับทางการค้า: ราคา สัญญา การเจรจา

รหัสผ่าน API key ข้อมูลเข้าระบบ

เอกสารที่มีชั้นความลับ ตามนโยบายบริษัท

[29:00] เชื่อมกับ PDPA: ข้อมูลสุขภาพ ศาสนา ประวัติอาชญากรรม ฯลฯ เป็นข้อมูลอ่อนไหวพิเศษ ข้อสังเกต: "ข้อมูลที่ประกาศแล้ว" เปลี่ยนจากแดงเป็นเขียวได้ เช่น งบการเงินหลังประกาศต่อตลาด
