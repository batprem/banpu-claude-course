อะไรคือ “ข้อมูลอ่อนไหว”

ข้อมูลส่วนบุคคล: เลขบัตร เงินเดือน บัญชีธนาคาร สุขภาพ

ข้อมูลการเงิน ที่ยังไม่เปิดเผยต่อสาธารณะ

ความลับทางการค้า: ราคา สัญญา การเจรจา

รหัสผ่าน API key ข้อมูลเข้าระบบ

เอกสารที่มีชั้นความลับ ตามนโยบายบริษัท

แล้วอะไรคือข้อมูลอ่อนไหวครับ มีห้ากลุ่มหลัก หนึ่ง ข้อมูลส่วนบุคคล เช่น เลขบัตร เงินเดือน บัญชีธนาคาร สุขภาพ ตาม PDPA ข้อมูลสุขภาพ ศาสนา หรือประวัติอาชญากรรม ถือเป็นข้อมูลอ่อนไหวพิเศษด้วย สอง ข้อมูลการเงินที่ยังไม่เปิดเผยต่อสาธารณะ สาม ความลับทางการค้า เช่น ราคา สัญญา การเจรจา สี่ รหัสผ่าน API key และข้อมูลเข้าระบบทั้งหมด และห้า เอกสารที่มีชั้นความลับตามนโยบายบริษัท มีข้อสังเกตนิดนึงครับ ข้อมูลเปลี่ยนสีได้ตามเวลา เช่น งบการเงิน ก่อนประกาศเป็นสีแดง แต่หลังประกาศต่อตลาดแล้ว กลายเป็นสีเขียวได้ ---------- [29:00] เชื่อมกับ PDPA: ข้อมูลสุขภาพ ศาสนา ประวัติอาชญากรรม ฯลฯ เป็นข้อมูลอ่อนไหวพิเศษ ข้อสังเกต: "ข้อมูลที่ประกาศแล้ว" เปลี่ยนจากแดงเป็นเขียวได้ เช่น งบการเงินหลังประกาศต่อตลาด
