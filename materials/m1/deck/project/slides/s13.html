Project

  • “ห้อง” ของงานหนึ่งเรื่อง: เก็บเอกสารและคำสั่งประจำไว้
  • ทุกแชตในห้องเห็นบริบทเดียวกัน ไม่ต้องอัปโหลดซ้ำ
  • แชร์ให้เพื่อนในทีมได้ (บัญชี Team ของบริษัท)
  • ระวัง: ไฟล์ใน Project ต้องผ่าน Data Traffic Light ก่อน
เครื่องมือที่สองคือ Project ครับ ให้นึกว่าเป็น "ห้อง" ของงานหนึ่งเรื่อง เราเก็บเอกสารและคำสั่งประจำไว้ในห้องนั้น ทุกแชตในห้องเห็นบริบทเดียวกัน ไม่ต้องอัปโหลดไฟล์ซ้ำ เช่น Project "รายงานประจำเดือน Site A ถึง H" เก็บ template คำอธิบายตัวชี้วัด และตัวอย่างรายงานเก่าไว้ ซึ่งเป็นข้อมูลสมมติ Project แชร์ให้เพื่อนในทีมได้ด้วยบัญชี Team ของบริษัท แต่ตรงนี้ต้องระวังครับ ใส่ไฟล์ครั้งเดียว ทุกคนที่เราแชร์ก็เห็นด้วย เพราะฉะนั้น ไฟล์ทุกไฟล์ที่จะใส่ใน Project ต้องผ่าน Data Traffic Light ก่อนเสมอ ซึ่งเราจะเรียนกันในส่วนที่สี่ครับ ---------- [11:00] ตัวอย่าง: Project "รายงานประจำเดือน Site A–H" เก็บ template + คำอธิบายตัวชี้วัด + ตัวอย่างรายงานเก่า (ข้อมูลสมมติ) ข้อควรระวัง: ใส่ไฟล์ครั้งเดียว ทุกคนที่แชร์เห็น ต้องคิดก่อนใส่
