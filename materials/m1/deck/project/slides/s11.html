5 เครื่องมือในภาพเดียว

เครื่องมือเหมาะกับตัวอย่าง
Chatงานสั้น ครั้งเดียวจบร่างอีเมล อธิบายสูตร
Projectหัวข้อเดียว ใช้บริบทเดิมซ้ำโครงการปิดเหมืองสมมติ
Skillวิธีทำงานแบบเดิม ใช้ซ้ำทุกหัวข้อรูปแบบรายงานมาตรฐาน
Agent (Cowork)หลายขั้น กับไฟล์/โฟลเดอร์รวม 20 ไฟล์ Excel
Artifactผลลัพธ์ที่ดู/กด/แชร์ได้dashboard, เกม, diagram
ดูห้าเครื่องมือในภาพเดียวก่อนครับ แล้วสไลด์ถัดไปเราจะลงทีละตัว Chat เหมาะกับงานสั้น ครั้งเดียวจบ เช่น ร่างอีเมล อธิบายสูตร Project เหมาะกับงานหัวข้อเดียวที่ใช้บริบทเดิมซ้ำ เช่น โครงการปิดเหมืองสมมติ Skill คือวิธีทำงานแบบเดิมที่ใช้ซ้ำได้ทุกหัวข้อ เช่น รูปแบบรายงานมาตรฐาน Agent หรือ Cowork เหมาะกับงานหลายขั้นที่ทำกับไฟล์และโฟลเดอร์ เช่น รวม Excel ยี่สิบไฟล์ และ Artifact คือผลลัพธ์ที่ดู กด หรือแชร์ได้ เช่น dashboard เกม หรือ diagram จุดที่คนสับสนบ่อยที่สุดคือ Project กับ Skill ครับ จำง่าย ๆ Project คือห้องเก็บบริบทของเรื่องหนึ่ง ส่วน Skill คือสูตรวิธีทำงาน ที่หยิบไปใช้ได้ทุกเรื่อง ---------- [9:00] อธิบายภาพรวมก่อน แล้วแต่ละสไลด์ถัดไปลงทีละตัว จุดที่คนสับสนบ่อย: Project vs Skill → Project = "ห้องเก็บบริบทของเรื่องหนึ่ง", Skill = "สูตรวิธีทำงานที่หยิบไปใช้ได้ทุกเรื่อง"
