5 นิสัยประหยัด usage

1

งานใหม่ = เริ่มแชตใหม่

2

ส่งเฉพาะส่วนที่ใช้ ไม่แนบทั้งไฟล์ถ้าไม่จำเป็น

3

เริ่มด้วย Sonnet ยกระดับเป็น Opus เมื่อจำเป็น

4

งานซ้ำ → ใช้ Project/Skill แทนพิมพ์คำสั่งยาว

5

ให้ Claude วางแผนก่อน ลดการทำผิดแล้วแก้ซ้ำ

สรุปเป็นห้านิสัยประหยัด usage ครับ หนึ่ง งานใหม่ เริ่มแชตใหม่ สอง ส่งเฉพาะส่วนที่ใช้ ไม่ต้องแนบทั้งไฟล์ถ้าไม่จำเป็น สาม เริ่มด้วย Sonnet แล้วค่อยยกระดับเป็น Opus เมื่อจำเป็น สี่ งานที่ทำซ้ำ ให้ใช้ Project หรือ Skill แทนการพิมพ์คำสั่งยาว ๆ ทุกครั้ง และห้า ให้ Claude วางแผนก่อน ข้อนี้เชื่อมกับ Plan → Approve → Execute ที่เราคุยกันครับ แผนที่ดีช่วยลดการทำผิดแล้วต้องแก้ซ้ำ ประหยัดทั้งเวลาและ usage ใน M8 เราจะมีแบบฝึกเลือก model และวิธีใช้ให้คุ้มอีกรอบครับ ---------- [38:00] ข้อ 5 เชื่อมกับ Plan → Approve → Execute: แผนที่ดีประหยัดทั้งเวลาและ usage M8 จะมีแบบฝึกเลือก model/วิธีให้คุ้ม
