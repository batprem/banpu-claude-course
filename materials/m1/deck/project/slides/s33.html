ธ.ค. 2025: Skill ที่ “ดูดี” แต่แอบซ่อนคำสั่ง

  • นักวิจัย Cato Networks นำ Skill แบบ open-source (สร้าง GIF) มาดัดแปลง
  • แทรกฟังก์ชันที่ดูปกติ แต่ไปดาวน์โหลดโค้ดภายนอกมารัน
  • ในเครื่องทดสอบ: ผู้ใช้อนุมัติครั้งเดียว → ไฟล์ถูกเข้ารหัสโดย ransomware
  • Anthropic ย้ำ: ผู้ใช้ต้องใช้เฉพาะ Skill ที่เชื่อถือได้

ติดตั้ง Skill = ติดตั้งโปรแกรม คิดแบบเดียวกัน

[34:00] เป็น proof-of-concept ในสภาพแวดล้อมทดสอบของนักวิจัย (Cato CTRL, 2 Dec 2025) ไม่ใช่การโจมตีบริษัทใด ใช้ให้เห็นว่าเป็นไปได้จริง จุดสอน: Claude ตรวจโค้ดที่มองเห็นได้ แต่ไม่เห็นโค้ดที่ถูกดาวน์โหลดภายหลัง → การอนุมัติครั้งแรกของคนจึงสำคัญมาก ที่มา: Cato Networks blog และ Axios (SOURCES #4, #5) · Anthropic enterprise Skills docs (SOURCES #3) ไม่ต้องลงรายละเอียดเทคนิค เน้นพฤติกรรม: "Skill ฟรีจากอินเทอร์เน็ต = โปรแกรมแปลกหน้า"
