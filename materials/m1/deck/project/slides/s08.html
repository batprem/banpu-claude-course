Plan → Approve → Execute

Plan · Claude เสนอแผน

Approve · คุณอนุมัติ

Execute · Claude ลงมือ

  • Cowork จะ เสนอแผนก่อน แล้วรอเรา
  • อ่านแผนเหมือนอ่านใบสั่งงาน: ไฟล์ไหน ทำอะไร ผลอยู่ที่ไหน
  • งานที่ ลบ ย้าย เขียนทับ ส่งออก ต้องมีจุดอนุมัติเสมอ
  • สงสัยตรงไหน สั่งแก้แผนได้ก่อนเริ่ม
  • ผลลัพธ์ = ร่าง จนกว่าคนจะตรวจ
สามคำนี้ทุกคนจะได้ยินทั้งวันครับ Plan → Approve → Execute Plan คือ Claude เสนอแผน Approve คือเราอนุมัติ Execute คือ Claude ลงมือ Cowork จะเสนอแผนก่อนแล้วรอเราเสมอ เวลาอ่านแผน ให้อ่านเหมือนอ่านใบสั่งงาน ไฟล์ไหน ทำอะไร ผลไปอยู่ที่ไหน งานที่ลบ ย้าย เขียนทับ หรือส่งออก ต้องมีจุดอนุมัติเสมอนะครับ ถ้าสงสัยตรงไหน สั่งแก้แผนได้ก่อนเริ่ม และข้อสุดท้าย ผลลัพธ์ที่ได้ยังเป็นแค่ร่าง จนกว่าคนจะตรวจ นี่คือหลัก Human-in-the-Loop ที่เราจะเจอในทุกโมดูล และใน M2 เราจะได้ฝึกจริงกับโฟลเดอร์ประมาณหนึ่งพันห้าร้อยไฟล์ครับ ---------- [6:00] หลัก Human-in-the-Loop (HITL) ที่จะเจอทุกโมดูล ใช้คำว่า "Plan → Approve → Execute" ให้ตรงกันทั้งหลักสูตร M2 จะฝึกจริงกับโฟลเดอร์ ~1,500 ไฟล์
