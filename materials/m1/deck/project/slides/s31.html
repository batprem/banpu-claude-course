ความเสี่ยงใหม่: Skill จากภายนอก

  • Skill = คำสั่ง + ไฟล์ + บางครั้งมี script ที่รันได้
  • แชร์กันง่ายบน GitHub/โซเชียล แต่ ยังไม่มีใคร audit
  • Skill ที่ไม่หวังดีอาจสั่งให้อ่านไฟล์หรือส่งข้อมูลออก
  • ใช้ Skill ที่บริษัทสร้างหรือรับรองก่อนเสมอ
ต่อไปเป็นความเสี่ยงใหม่ครับ Skill จากภายนอก อย่างที่บอกไป Skill คือคำสั่ง บวกไฟล์ และบางครั้งมี script ที่รันได้ Skill แบบนี้แชร์กันง่ายมากบน GitHub หรือโซเชียล แต่ยังไม่มีใคร audit Skill ที่ไม่หวังดี อาจสั่งให้ Claude อ่านไฟล์ หรือส่งข้อมูลออกไปข้างนอกได้ เรื่องนี้ Anthropic เองก็เขียนไว้ในเอกสาร Skills สำหรับองค์กรว่า Skill ที่ไม่หวังดีอาจสั่งให้ Claude รันโค้ด เข้าถึงไฟล์ หรือส่งข้อมูลออก และไม่ควรใช้ Skill จากแหล่งที่ไม่น่าเชื่อถือโดยไม่ audit หลักของเราจึงง่ายครับ ใช้ Skill ที่บริษัทสร้างหรือรับรองก่อนเสมอ วันนี้รู้แนวคิดไว้ก่อน แล้วเราจะลงมือตรวจจริงด้วย checklist ใน M5 ---------- [32:00] Requirement 9 ระดับ "แนะนำแนวคิด" ใน M1 ลงมือตรวจจริงด้วย checklist ใน M5 ที่มา: Anthropic เอกสาร Skills สำหรับองค์กร: Skill ที่ไม่หวังดีอาจสั่งให้ Claude รันโค้ด เข้าถึงไฟล์ หรือส่งข้อมูลออก และไม่ควรใช้ Skill จากแหล่งที่ไม่น่าเชื่อถือโดยไม่ audit (SOURCES #3)
