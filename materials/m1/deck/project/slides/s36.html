Weekly usage limit: รู้ไว้ก่อนชน

  • Team plan มี โควตาต่อคน ต่อรอบการใช้งาน และรายสัปดาห์
  • ดูการใช้และเวลารีเซ็ตที่ Settings → Usage
  • ใช้มากเมื่อ: แชตยาว · ไฟล์ใหญ่ · model ใหญ่ · Agent ทำหลายขั้น
  • Artifact ที่เรียก AI ข้างในก็ใช้โควตา
  • ชนแล้วต้องรอรอบใหม่ → วางแผนงานใหญ่ให้ดี
เรื่อง Weekly usage limit ครับ รู้ไว้ก่อนชน Team plan มีโควตาต่อคน ทั้งต่อรอบการใช้งาน และรายสัปดาห์ เป็นโควตาของแต่ละคน ไม่ได้รวมกันทั้งทีม เข้าไปดูการใช้และเวลารีเซ็ตได้ที่ Settings แล้วไปที่ Usage ผมเปิดให้ดูตรงนี้เลยครับ อะไรที่ใช้โควตามาก แชตยาว ไฟล์ใหญ่ model ใหญ่ และ Agent ที่ทำหลายขั้น Artifact ที่เรียก AI อยู่ข้างในก็ใช้โควตาเหมือนกัน ถ้าชนแล้ว ต้องรอรอบใหม่ เพราะฉะนั้นงานใหญ่ต้องวางแผนให้ดีครับ ส่วนตัวเลขโควตาที่แน่นอน ขึ้นกับการตั้งค่าของบริษัท ณ ช่วงนั้น ผมเลยไม่ให้ตัวเลขตายตัวนะครับ ---------- [37:00] โชว์หน้า Settings → Usage จริง (ถ้าเปิดได้) ตัวเลขและรอบรีเซ็ตขึ้นกับการตั้งค่าของบริษัท/Anthropic ณ วันอบรม ให้ยืนยันใน dry-run อย่าให้ตัวเลขโควตาเฉพาะเจาะจงในห้อง เพราะเปลี่ยนได้ ข้อเท็จจริงจาก Help Center (SOURCES #6): limit เป็นรายคน ไม่ใช่รวมทั้งทีม · weekly limit รีเซ็ตเวลาคงที่ของแต่ละบัญชี · ที่นั่ง Standard/Premium ต่างกัน · องค์กรเปิด usage credits ให้ใช้ต่อหลังชน limit ได้ (ขึ้นกับการตั้งค่าของ admin บ้านปู)
