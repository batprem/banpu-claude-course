บัญชีที่ใช้: Claude Team ของบริษัท เท่านั้น

Claude ที่เราใช้ในบริษัท มีสี่ส่วนหลักครับ ส่วนแรกคือ Chat ใช้ถาม-ตอบ ร่างข้อความ หรือสรุปไฟล์ที่แนบ ส่วนที่สองคือ Cowork ซึ่งอยู่ใน Claude Desktop ตัวนี้คือ Agent ที่ทำงานกับไฟล์และโฟลเดอร์ในเครื่องเราได้หลายขั้นตอน ส่วนที่สามคือ Connector ใช้เชื่อมกับ SharePoint และ Outlook ของ M365 ที่ IT อนุมัติแล้ว ในหลักสูตรนี้เราใช้แค่สองตัวนี้ครับ และจะลงลึกกันใน M3 ส่วนสุดท้ายคือ Artifact ผลงานที่เปิดดูหรือกดเล่นได้ เช่น dashboard หรือ app เล็ก ๆ สำคัญที่สุดคือบรรทัดล่างนี้ครับ บัญชีที่ใช้ทำงานคือ Claude Team ของบริษัทเท่านั้น ---------- [3:00] เปิด Claude Desktop ให้เห็นแท็บ Chat และ Cowork สั้น ๆ (ถ้ามีจอ) ย้ำ: connector ที่ใช้ในหลักสูตรมีแค่ SharePoint และ Outlook จะลงลึกใน M3
