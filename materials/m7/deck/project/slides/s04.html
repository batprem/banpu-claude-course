นี่คือหัวใจของ capstone ครับ กรอบคิดเดียวที่ทุกคนต้องตอบให้ครบก่อนลงมือ คือ Data, Connector, Output และ Trade-off บวกจุด HITL เริ่มที่ Data ข้อมูลอยู่ที่ไหน ใครเป็นเจ้าของ และเป็นสีอะไรตาม Data Traffic Light ที่เราเรียนใน M1 ต่อด้วย Connector จะดึงข้อมูลผ่าน SharePoint หรือ Outlook แบบใน M3 หรือใช้โฟลเดอร์ใน Cowork แบบใน M2 Process คือ Claude หรือ Cowork ทำอะไรให้เรา แล้ว HITL ใครตรวจ ตรวจตรงไหน Output เลือกตามคนอ่านครับ จะเป็น Word, Excel, PPTX, Artifact หรือร่างอีเมล ใช้ Output Picker จาก M4 ช่วยเลือกได้เลย ช่องสุดท้ายคือ Trade-off เดี๋ยวสไลด์หน้าจะลงรายละเอียด สังเกตเส้นประที่วนกลับไปที่ Data นะครับ หลายครั้งทางแก้ trade-off คือลดขอบเขตข้อมูล เช่น ใช้แค่ตารางสรุป ไม่ใช้ข้อมูลรายบุคคล ---------- [3:00] ~1 นาที · นี่คือ requirement 14 ทั้งข้อในภาพเดียว · ทุกคนต้องตอบครบ 4 ช่อง (+ จุด HITL) ก่อนลงมือ Data: ที่อยู่ เจ้าของ สีตาม Data Traffic Light (M1) Connector: SharePoint / Outlook (M3) หรือโฟลเดอร์ใน Cowork (M2) — ไม่มี Google Drive Output: เลือกตามคนอ่าน (Output Picker ของ M4) · Trade-off: ดูสไลด์ถัดไป เส้นประกลับไปที่ Data = “ปรับขอบเขต”: บ่อยครั้งทางแก้ Trade-off คือ “ลดขอบเขตข้อมูล”
