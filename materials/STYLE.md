# Style & conventions (shared by all modules)

Owner: course-orchestrator. Module workers read this before writing anything. Do not edit this file; ask the orchestrator.

## Language and tone
- Learner-facing text is **Thai**. Keep product/technical terms in English: Claude, Cowork, Chat, Project, Skill, Plugin, Agent, Artifact, Connector, SharePoint, Outlook, Human-in-the-Loop, Prompt, Scheduled task, Export PDF.
- Speaker notes may mix Thai and English.
- Address learners as "เรา/คุณ", friendly-professional. Short sentences, max ~6 bullets per slide, ~12 words per bullet.

## Fixed terminology (use exactly)
| Concept | Write it as |
|---|---|
| Human checkpoint | Human-in-the-Loop (HITL) · จุดให้คนตรวจ/อนุมัติ |
| Approval flow | Plan → Approve → Execute |
| Connector flow | AI → Connect → Data → Execute |
| Safe edit rule | copy-before-write (ทำสำเนาก่อนให้ Claude แก้) |
| Prompt framework | Input → Process → Output |
| Report pipeline | Document Factory: Multiple Sources → Process → Report → Schedule/Distribution |
| Data classes | Data Traffic Light: 🟢 เขียว ใช้ได้ · 🟡 เหลือง ต้อง anonymize · 🔴 แดง ห้ามใส่ Claude |
| Prompt patterns (M2) | 1) Use your own words 2) Interview pattern 3) Prototype first |
| Plans | Personal / Team / Enterprise |
| Fictional company context | "บ้านปู" business context but every number, name, site and email is synthetic. Sites: use fictional names `Site A–H` or invented names (e.g. "เหมืองสมมติ ภูผาทอง", "โรงไฟฟ้าสมมติ ลำน้ำใส"). People: obviously fictional Thai names. Emails `@example.com` only. |

Never use real Banpu data, employee names, financials, or real site production figures. Google Drive is never shown or suggested; only SharePoint and Outlook (M365). Copilot is out of scope.

## Diagrams — every workflow gets one
Write diagrams as Mermaid in `.mmd` files under `materials/<mN>/diagrams/` and embed the same code in slides with a ```` ```mermaid ```` block. Always include these class definitions and assign every node a class:

```
classDef human fill:#E4572E,color:#fff,stroke:#1F2933;
classDef ai fill:#2E86AB,color:#fff,stroke:#1F2933;
classDef data fill:#3BA55C,color:#fff,stroke:#1F2933;
```
Add a one-line legend under each diagram in slides: `🟧 คน (HITL) · 🟦 AI · 🟩 Data/Connector`.

## Slides
- Source: `materials/<mN>/slides.md`, rendered with `python3 tools/build_slides.py materials/<mN>/slides.md` → `slides.html` (16:9, print to PDF = 1 slide/page).
- Format: YAML-ish front matter, then slides separated by a line containing only `---`. Speaker notes go after a line containing only `???`.
- Budget: Lecture = 1 slide per lecture minute (± 10%). Workshop = 1 guide page per 5 workshop minutes.
- Slide types: use `<!-- type: section -->` as the first line of a slide for section dividers, `<!-- type: story -->` for story/case slides.
- Images: `materials/<mN>/img/…`, referenced relatively (`img/foo.png`). Each external image needs a SOURCES entry with licence.

## Workshop guide
- `materials/<mN>/workshop.md`. A "page" = one `## ` section intended to fit one A4 page. Each step states: เป้าหมาย, Prompt (copy-ready in a code block), ✅ checkpoint (what the human checks), time.
- Prompt templates: `materials/<mN>/prompts.md`, each prompt with an ID like `M2-P03`.

## Learner Artifacts
- `materials/<mN>/artifacts/<name>.html`, single self-contained HTML file meant to be pasted into Claude as an Artifact (or opened locally). Plus `materials/<mN>/artifacts/<name>.spec.md` (purpose, users, interactions, data, engagement mechanic).
- Must include an **Export PDF** button using the snippet in `materials/_shared/export-pdf.html` (window.print + print CSS that hides controls and shows all content).
- No external network calls except fonts/CDN libraries; no real data; no calls to AI from the Artifact unless the spec justifies it (it consumes Team plan usage).
- Font: `IBM Plex Sans Thai` (Google Fonts). Colours from the table above.

## Stories & sources
- Each module: at least one story or real public case, with a source link.
- Do NOT edit `materials/SOURCES.md` directly. Write `materials/<mN>/SOURCES.md` (table: # · item · used in · URL · author/owner · licence/usage rights · accessed date). The orchestrator merges.
- Prefer: official Anthropic docs/blog, Microsoft Learn, public talks/repos with clear licences (e.g. Matt Pocock's "grill me" skill for the Interview pattern). Screenshots of public product UI are referenced with source URL; if rights are unclear, mark `link-only` and do not copy the image.

## Module folder layout
```
materials/<mN>/
  README.md        # overview, timing table, requirement coverage, page counts
  slides.md        # lecture deck source (+ slides.html generated)
  workshop.md      # workshop guide
  prompts.md       # copy-ready prompt templates
  diagrams/*.mmd
  artifacts/*.html + *.spec.md
  data/            # synthetic sample data this module needs (+ generator scripts)
  img/
  SOURCES.md
```
Large generated data (> 5 MB) is not committed: commit the generator script under `data/` and add the output path to `materials/<mN>/data/.gitignore`.
