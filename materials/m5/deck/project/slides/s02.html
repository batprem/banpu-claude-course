ก.พ. 2026: Skill ปลอม 341 ตัว ในร้าน Skill สาธารณะ

  • ClawHub = ร้านแจก Skill ฟรีของ AI agent ชื่อ OpenClaw (ไม่ใช่ Claude)
  • Koi Security ตรวจ 2,857 Skill พบ 341 ตัวที่เป็นมัลแวร์
  • หน้าตาเหมือนเครื่องมือยอดนิยม แต่ให้ติดตั้ง “prerequisite” ก่อน
  • ผลคือโปรแกรมขโมยรหัสผ่าน และส่ง credential ออกไปภายนอก
  • ใครก็อัปโหลดได้: แค่มีบัญชี GitHub อายุ 1 สัปดาห์

Skill คือไฟล์ข้อความธรรมดา จึงแชร์ง่าย และปลอมง่ายพอ ๆ กัน

ก่อนเริ่ม ผมขอเล่าเรื่องจริงเรื่องหนึ่งครับ เดือนกุมภาพันธ์ 2026 มีร้านแจก Skill ฟรีชื่อ ClawHub เป็นของ AI agent ชื่อ OpenClaw ซึ่งไม่ใช่ Claude นะครับ บริษัท Koi Security เข้าไปตรวจ 2,857 Skill แล้วพบว่า 341 ตัวเป็นมัลแวร์ หน้าตาเหมือนเครื่องมือยอดนิยม แต่บอกให้ติดตั้ง "prerequisite" ก่อน ผลคือได้โปรแกรมขโมยรหัสผ่าน และ credential ถูกส่งออกไปข้างนอก ที่น่ากลัวคือใครก็อัปโหลดได้ แค่มีบัญชี GitHub อายุหนึ่งสัปดาห์ ถึงจะเป็นคนละ agent กับ Claude แต่ใช้แนวคิดเดียวกัน คือ Skill เป็นโฟลเดอร์กับไฟล์ SKILL.md ความเสี่ยงจึงเป็นแบบเดียวกันครับ เมื่อเช้าใน M1 เราเห็นเคส Cato Networks ที่นักวิจัยทดลอง ตอนนี้คือของจริงในวงกว้างแล้ว Skill เป็นไฟล์ข้อความธรรมดา จึงแชร์ง่าย และปลอมง่ายพอ ๆ กัน ขอถามหน่อยครับ ถ้าเพื่อนส่ง Skill ที่ทำรายงานสวยมากมาให้ทาง LINE คุณจะติดตั้งเลยไหม? เก็บคำตอบไว้ก่อน เดี๋ยวเราได้ตรวจกันจริงใน Workshop ครับ ---------- [0:30] เล่า 1 นาที เป็นเคสจริงจากข่าว The Hacker News, ก.พ. 2026 (SOURCES #1) และ eSecurity Planet (SOURCES #2) ย้ำว่าเป็น agent คนละตัวกับ Claude แต่ใช้แนวคิด "Skill = โฟลเดอร์ + SKILL.md" เหมือนกัน ความเสี่ยงจึงเป็นแบบเดียวกัน เชื่อมกับ M1: เคส Cato Networks (นักวิจัยทดลอง) → ตอนนี้คือของจริงในวงกว้าง คำถามชวนคิดเรื่อง LINE: ไม่ต้องเฉลย เก็บคำตอบไว้ใช้ใน workshop
