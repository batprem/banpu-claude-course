คืออะไรใช้เมื่อตัวอย่าง
Promptคำสั่งงานครั้งนี้งานเดียวจบ“สรุปไฟล์นี้”
Projectห้องเก็บบริบทของเรื่องหนึ่งคุยเรื่องเดิมต่อเนื่องโครงการปิดเหมืองสมมติ
Skillวิธีทำงานที่ใช้ซ้ำได้ทุกเรื่องงานรูปแบบเดิมซ้ำ ๆรายงานมาตรฐาน
Connectorท่อเชื่อมข้อมูลต้องอ่าน/เขียนระบบอื่นSharePoint · Outlook
Pluginกล่องรวม Skill + Connector + คำสั่ง /ชุดเครื่องมือของบทบาทงานชุดงานการเงินสมมติ
ทวนจาก M1 สั้น ๆ ครับ แล้วเราเพิ่มอีกสองตัว Prompt คือคำสั่งงานครั้งนี้ ใช้กับงานเดียวจบ เช่น "สรุปไฟล์นี้" Project คือห้องเก็บบริบทของเรื่องหนึ่ง ใช้เมื่อคุยเรื่องเดิมต่อเนื่อง เช่นโครงการปิดเหมืองสมมติ Skill คือวิธีทำงานที่ใช้ซ้ำได้ทุกเรื่อง เหมาะกับงานรูปแบบเดิมซ้ำ ๆ อย่างรายงานมาตรฐาน ตัวใหม่ตัวแรกคือ Connector ที่เราเจอใน M3 เป็นท่อเชื่อมข้อมูลไป SharePoint กับ Outlook ตัวสุดท้ายคือ Plugin เป็นกล่องรวม Skill, Connector และคำสั่ง slash ไว้เป็นชุดเครื่องมือของบทบาทงาน เช่นชุดงานการเงินสมมติ ประโยคจำง่าย ๆ ครับ Project คือ "เรื่องอะไร" Skill คือ "ทำอย่างไร" Connector คือ "ข้อมูลอยู่ไหน" Plugin คือ "แพ็กรวมทั้งหมดให้ทีม" และทั้งหมดใช้ร่วมกันได้นะครับ เช่น Project รายงานประจำเดือน คู่กับ Skill รายงานมาตรฐาน และ Connector SharePoint ครับ ---------- [3:30] ทวนจาก M1 สั้น ๆ แล้วเพิ่ม 2 ตัวใหม่: Connector (M3) และ Plugin Plugin ใน Cowork รวม Skill, Connector, slash command และ sub-agent เป็นชุดเดียว (SOURCES #5, #6) ข้อควรระวัง: ติดตั้ง Plugin ได้เฉพาะที่ admin อนุญาต · Plugin ที่มี Connector อื่นนอกจาก SharePoint/Outlook ไม่อยู่ในขอบเขตของบริษัท
