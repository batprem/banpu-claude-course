45 นาทีนี้ เราจะได้หกเรื่องครับ หนึ่ง เข้าใจภาพ AI → Connect → Data → Execute ว่า Claude ไปหยิบข้อมูลมาอย่างไร สอง ใช้เฉพาะ Connector ที่ IT เปิดให้ คือ SharePoint กับ Outlook สาม แยกให้ออกว่าอะไรคือ Read อะไรคือ Write แล้ว Write เสี่ยงตรงไหน สี่ ใช้ copy-before-write ทุกครั้งที่ให้ Claude แก้ไฟล์ ห้า ค้นอีเมล ไฟล์ และ List แล้วได้สรุปเดียวพร้อมที่มา และหก รู้ข้อจำกัดของ Connector กับทางเลี่ยงครับ ครึ่งหลัง ทุกคนจะได้ลงมือเองกับกล่องจดหมายทดสอบ และ SharePoint ทดสอบ ที่มีแต่ข้อมูลสมมติ ไม่ต้องกังวลเรื่องข้อมูลจริงเลยครับ ถ้าบัญชีทดสอบยังไม่พร้อม เรามีโฟลเดอร์ Sample Pack ในเครื่องเป็นเส้นทางสำรอง ได้ฝึกเหมือนกันครับ ---------- [0:30] อ่านเร็ว ๆ ไม่ต้องลงรายละเอียดทีละข้อ ครึ่งหลังลงมือกับ “กล่องจดหมายทดสอบ” และ “SharePoint ทดสอบ” ที่มีข้อมูลสมมติ ถ้า IT ยังไม่ได้เตรียม test tenant: เส้นทางสำรองคือโฟลเดอร์ Sample Pack ในเครื่อง ได้ฝึกเหมือนกัน
