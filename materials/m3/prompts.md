## M3-P01 · เช็กว่า Connector เห็นอะไร (อ่านอย่างเดียว)

```text
ใช้ Microsoft 365 connector แบบอ่านอย่างเดียว ห้ามแก้ไข ห้ามส่ง ห้ามสร้างอะไร
1) ค้นอีเมลใน Outlook ที่หัวเรื่องขึ้นต้นด้วย [PRJ- ในช่วง 30 วันที่ผ่านมา บอกจำนวนและ 3 หัวเรื่องล่าสุด
2) ค้นไฟล์ใน SharePoint site "M3-Training" ที่ชื่อมีคำว่า Tracker หรือ Issue บอกชื่อไฟล์และวันที่แก้ไขล่าสุด
ถ้าค้นไม่เจอ ให้บอกตรง ๆ ว่าไม่เจอ อย่าเดา
```

## M3-P02 · สรุปสถานะโครงการจาก 3 แหล่ง → 1 หน้า

```text
บทบาท: ผู้ช่วย Project Control (ข้อมูลทั้งหมดเป็นข้อมูลสมมติ)
แหล่งที่อนุญาต (อ่านอย่างเดียว):
- Outlook: อีเมลที่หัวเรื่องมี [PRJ-, "ขออนุมัติ", "สรุปประชุม" ช่วง 1–28 ต.ค. 2569
- SharePoint site "M3-Training": Project_Tracker.csv, Issue_Log.csv, Shared_Capex_Tracker_2569.xlsx
ห้ามค้นนอกแหล่งเหล่านี้

งาน: ทำสรุปสถานะโครงการ 1 หน้า เป็นภาษาไทย
1) ตารางโครงการที่ At risk / Delayed หรือมีสัญญาณเสี่ยงในอีเมล (ProjectID, เรื่อง, สถานะใน Tracker, สิ่งที่อีเมลบอก)
2) ความเสี่ยงสูงสุด 3 เรื่อง พร้อมเหตุผล
3) คำขออนุมัติที่ยังค้าง: ใครขอ ขออะไร วงเงิน กำหนดเวลา
4) "จุดที่แหล่งข้อมูลขัดกัน" อย่างน้อย 1 จุด
กติกา: ทุกข้อต้องอ้างที่มา (หัวเรื่องอีเมล+วันที่ หรือ ชื่อไฟล์+แถว/แท็บ) ถ้าไม่แน่ใจให้เขียนว่า "ต้องตรวจ"
ท้ายสรุป: แสดงรายการแหล่งที่ใช้จริงทั้งหมด
```

## M3-P03 · ค้นเจาะจง (ภารกิจในหน้า 3)

```text
อ่านอย่างเดียว ใช้เฉพาะ Outlook และ SharePoint site "M3-Training"
คำถาม: [วางคำถามของภารกิจ เช่น "PRJ-105 ขออนุมัติงบเพิ่มเท่าไร ทำไม ต้องตอบภายในวันไหน และงบใน Capex Tracker ตอนนี้เท่าไร"]

ถ้าสองแหล่งให้ตัวเลขไม่ตรงกัน ให้แสดงทั้งสองค่า อย่าเลือกเอง
```

## M3-P04 · ตรวจที่มาและจุดที่ขัดกัน

```text
ทบทวนสรุปที่คุณเพิ่งทำ:
1) ข้อไหนที่อ้างที่มาไม่ได้ชัด ให้ทำเครื่องหมาย ⚠️
2) ตัวเลขทุกตัว (งบ วงเงิน %) มาจากแหล่งไหน แสดงเป็นตาราง ตัวเลข | แหล่ง | ตรงกันทุกแหล่งไหม
3) มีอีเมลหรือไฟล์ในขอบเขตที่คุณไม่ได้อ่านไหม บอกตรง ๆ
ห้ามแก้สรุปเอง ให้ฉันตัดสินใจ
```

## M3-P05 · ทำสำเนาก่อนแก้ (copy-before-write)

```text
ในโฟลเดอร์นี้มี Shared_Capex_Tracker_2569.xlsx (ข้อมูลสมมติ ไฟล์ที่หลายคนแก้ร่วมกัน)
ขั้นแรก ห้ามแก้ไฟล์ต้นฉบับเด็ดขาด
1) ทำสำเนาชื่อ _COPY_Shared_Capex_Tracker_2569_[ชื่อเล่นของฉัน]_[วันที่ YYYYMMDD].xlsx ในโฟลเดอร์เดียวกัน
2) ยืนยันว่าสำเนามีครบทุกแท็บ และสูตรในแท็บ Summary ยังเป็นสูตร (ไม่ใช่ตัวเลข)
3) รายงานชื่อไฟล์สำเนา แล้วหยุดรอคำสั่ง
```

## M3-P06 · ให้ Claude เสนอแผนแก้สำเนา (Plan → Approve → Execute)

```text
ทำงานกับไฟล์สำเนา _COPY_... เท่านั้น
เป้าหมาย: อัปเดตแท็บ "Site D" แถว PRJ-105 ให้ Forecast_MTHB = 98.8 และ Note = "รออนุมัติงบเพิ่ม 3.8 ลบ. (อีเมล 26 ต.ค.)"
ก่อนลงมือ ให้เสนอแผนเป็นข้อ ๆ: เซลล์ไหนจะเปลี่ยน ค่าเดิม → ค่าใหม่
กติกา: ห้ามแตะแท็บอื่น ห้ามเปลี่ยนสูตร ห้ามลบแถว/คอลัมน์ ห้ามเปลี่ยน format
รอฉันพิมพ์ "อนุมัติ" ก่อนแก้
หลังแก้: เพิ่ม 1 แถวในแท็บ Change_Log (เวลา, "Claude (ทดลอง)", Site D, สิ่งที่แก้) และแสดงตารางสิ่งที่เปลี่ยนทั้งหมด
```

## M3-P07 · ตรวจก่อนบันทึก (diff + สูตร + แท็บคนอื่น)

```text
เปรียบเทียบไฟล์ต้นฉบับกับไฟล์ _COPY_... แบบอ่านอย่างเดียว แล้วรายงาน:
1) ทุกเซลล์ที่ต่างกัน: แท็บ | เซลล์ | ค่าเดิม | ค่าใหม่
2) มีเซลล์ที่เคยเป็นสูตรแล้วกลายเป็นตัวเลขไหม
3) มีการเปลี่ยนในแท็บอื่นนอกจาก Site D และ Change_Log ไหม
4) dropdown คอลัมน์ Status และความกว้างคอลัมน์ยังเหมือนเดิมไหม
สรุปท้าย: "พร้อมให้เจ้าของไฟล์นำไปใส่ต้นฉบับ" หรือ "ยังไม่พร้อม เพราะ..." ห้ามแก้ไฟล์ใด ๆ ในขั้นนี้
```

## M3-P08 · เส้นทาง B: ไม่มี test tenant (ใช้โฟลเดอร์ M3_SamplePack)

