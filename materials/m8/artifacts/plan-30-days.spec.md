# Spec · แผน 30 วันของฉัน (30-day plan)

- **Purpose:** every learner leaves with one small, real adoption plan: 1 use case · 4 weeks · a buddy · Friday check-ins · measurable result. Covers M8 "แผน 30 วัน" and reinforces requirements 2, 3, 9, 13 (data colour, approved connectors, third-party Skills, usage).
- **Users:** each learner, solo, workshop page 4 (8 minutes); revisited after class at each Friday check-in.
- **Sections:** 1 me + buddy + manager + start Monday + link to the M7 team card · 2 main use case (+ 2 backups): task, data colour 🟢/🟡/🔴, tools (Chat/Project/Skill/Cowork/Artifact) and connectors (SharePoint/Outlook only), HITL checkpoint; idea chips for a quick start · 3 four week cards (editable; same plan as the slide: choose a 🟢 task + Project → do it 3× and time it → Skill/template + invite a colleague → measure, share, decide) with Friday check-in dates computed from the start date · 4 measurement: minutes before/after, times in 30 days, success criterion · 5 six rules to tick.
- **Engagement mechanic:** readiness meter (10 checks → %), "hours saved in 30 days" counter, live warnings (🔴 data → choose another task; Cowork without HITL; 🟡 needs anonymisation; no buddy; target not faster), "ดูตัวอย่างแผน" example, copy button for prompt M8-P03 (Interview pattern).
- **Data:** none; examples are fictional. Plan saved in `localStorage` (this browser only, try/catch). Nothing is sent anywhere.
- **Export PDF:** button + print CSS; prints the filled plan (unselected chips and controls hidden, print date shown) for the learner to store in SharePoint/OneDrive.
- **AI calls:** none (no Team-plan usage).
