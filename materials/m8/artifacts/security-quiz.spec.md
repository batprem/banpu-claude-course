# Spec · Security & Usage Quiz (`security-quiz.html`)

## Purpose
ปิดวันด้วยการทบทวนกฎ 6 ข้อ (requirement 2, 3, 9, 13) แบบมีคะแนน ให้ผู้เรียนเห็นเองว่าหมวดไหนยังไม่แน่น และเก็บ PDF ผลไว้เป็นหลักฐานการผ่านอบรม
ใช้ใน workshop M8 ภารกิจ 2 (หน้า 2–3) และ debrief สไลด์ 18

## Users
- ผู้เรียน ~30–40 คนต่อคลาส (รวม 200+ คน) ทำเดี่ยวบนเครื่องตัวเอง 9 + 3 นาที
- วิทยากรใช้ `trainer/answer-key.md` (สร้างอัตโนมัติ) ตอน debrief

## Content / data
- 18 ข้อ 6 หมวด: ข้อมูลอ่อนไหว · บัญชี & การแชร์ · Connector & copy-before-write · Human-in-the-Loop · Skill จากภายนอก · ใช้ให้คุ้ม (2–4 ข้อต่อหมวด) ทุกข้อเป็นสถานการณ์สมมติ ภาษาไทย มีเหตุผล + "ทวนที่" (โมดูลต้นทาง)
- รอบสุดท้าย: การ์ด Data Traffic Light 6 ใบ (C05, C07, C10, C12, C14, C15) อ่านจาก `materials/m1/data/traffic_light_cards.json` **แบบอ่านอย่างเดียว** เลือกใบที่ผสมทั้ง 3 สีและเป็นใบที่คนพลาดบ่อยใน M1
- Source of truth: `data/quiz_questions.json` → `python3 materials/m8/data/sync_quiz.py` ฝังข้อมูลลงบล็อก `<script type="application/json" id="quiz-data">` และสร้าง `trainer/answer-key.md` ใหม่ ห้ามแก้ข้อมูลในไฟล์ HTML ตรง ๆ

## Interactions
1. ตอบทีละข้อ (สลับลำดับตัวเลือกทุกครั้ง ป้องกันการบอกต่อ "ข้อ B") · คีย์ลัด 1–4 · Enter ไปต่อ
2. หลังตอบ: ไฮไลต์ถูก/ผิด + เหตุผล + ทวนที่ แม้ตอบถูก
3. รอบสุดท้าย: การ์ดละ 10 วินาที (ตั้งค่าได้ `final_round.seconds_per_card`) ปุ่ม 🟢/🟡/🔴 หรือคีย์ 1–3 หมดเวลา = 0 คะแนน
4. หน้าผล: คะแนนรวม /24 · badge 4 ระดับ · แถบคะแนนรายหมวด (เขียว ≥80% · ส้ม ≥60% · แดง <60%) · "หมวดที่ควรทบทวน" · เฉลยทุกข้อพร้อมคำตอบของเรา
5. "ทำเฉพาะข้อที่พลาดอีกรอบ" (คะแนนอัปเดต ข้อที่ตอบใหม่ติดป้าย "(ตอบใหม่)") · "เริ่มใหม่"
6. ช่องชื่อ (ไม่บังคับ) แสดงบนหัว PDF

## Engagement mechanic
คะแนน + ตัวนับ "ถูกติดกัน 🔥" + แถบความคืบหน้า · รอบสุดท้ายจับเวลาให้ตื่นตัวช่วงท้ายวัน · badge ("Security Champion" ≥ 90%) ใช้ให้ห้องยกมือแข่งกันตอน debrief

## Export PDF
ปุ่ม `⬇ Export PDF` จาก `materials/_shared/export-pdf.html` + print CSS: ซ่อนแผงตอบคำถาม แสดงหน้าผลเสมอ (แม้ยังทำไม่ครบ จะบอก "ตอบแล้ว n/24") พร้อมชื่อ วันที่ คะแนนรายหมวด และเฉลยทุกข้อ (A4 ~4–5 หน้า) ทดสอบด้วย headless Chrome `--print-to-pdf`

## Privacy / usage
- ไม่เรียก AI ไม่ใช้ usage ของ Team plan · ไม่มี network call นอกจาก Google Fonts
- คะแนนเก็บใน `localStorage` ของเครื่องนี้เท่านั้น (ห่อ try/catch; ถ้าเปิดเป็น Artifact ที่ไม่มี storage ก็ยังทำงาน แค่ไม่จำความคืบหน้า) ไม่ส่งไปที่ใด
- ถ้า Hi-I ต้องการเก็บคะแนนรวม: ให้ผู้เรียนแนบ PDF ใน Microsoft Forms/SharePoint ที่ Hi-I เตรียม (Open question ใน README)

## Acceptance
เปิดไฟล์เดี่ยวได้ · ตอบครบ 18 + 6 แล้วเห็นผล · Export PDF แสดงผลรวม + เฉลย · ใช้งานได้ที่ความกว้างมือถือ (ปุ่มไฟเรียงแนวตั้ง < 560px)
