Scheduled task ใน Cowork คืออะไร

  • Prompt ที่ บันทึกไว้ + ตั้งรอบ ให้ Claude ทำเองตามเวลา
  • รอบ: ทุกชั่วโมง · ทุกวัน · ทุกสัปดาห์ · วันทำการ · กดรันเอง
  • สร้างได้ 2 ทาง: Scheduled → New task หรือพิมพ์ /schedule ในแชต Cowork
  • ใช้ Connector, Skill, Plugin ได้เหมือนงานปกติ
  • ตั้ง Approval mode ได้: ให้ถามก่อนทุกครั้ง (เราใช้แบบนี้)
  • ดูประวัติ · แก้ · Pause · Run now เพื่อทดสอบได้ทุกเมื่อ
แล้ว Scheduled task ใน Cowork คืออะไร ง่าย ๆ ครับ มันคือ Prompt ที่เราบันทึกไว้ แล้วตั้งรอบให้ Claude ทำเองตามเวลา รอบที่ตั้งได้ก็มี ทุกชั่วโมง ทุกวัน ทุกสัปดาห์ เฉพาะวันทำการ หรือกดรันเองก็ได้ สร้างได้ 2 ทาง ทางแรกเข้าเมนู Scheduled แล้วกด New task ทางที่สองพิมพ์ /schedule ในแชต Cowork ข้างใน task ใช้ Connector, Skill, Plugin ได้เหมือนงานปกติทุกอย่าง จุดที่สำคัญที่สุดคือ Approval mode ครับ เราตั้งให้มันถามก่อนทุกครั้งได้ และในคอร์สนี้เราจะใช้แบบนี้ เดี๋ยวผมเปิดหน้าจอจริงให้ดูนะครับ ตรงนี้คือ Set up manually มีช่องชื่องาน prompt approval mode ความถี่ ส่วน model กับโฟลเดอร์ไม่บังคับ ถ้าไม่อยากเขียนเอง กด Create with Claude ให้ Claude สัมภาษณ์เราแล้วเขียน task ให้ เหมือน Interview pattern ที่เราเรียนใน M2 แล้วเราดูประวัติ แก้ Pause หรือกด Run now เพื่อทดสอบได้ทุกเมื่อครับ ---------- [1:45] เปิดหน้า Scheduled ใน Claude Desktop ให้ดูของจริง 20 วินาที (SOURCES #1, #2) หน้าต่าง “Set up manually”: ชื่องาน · prompt · approval mode · ความถี่ · model (ไม่บังคับ) · โฟลเดอร์ (ไม่บังคับ) “Create with Claude” = Claude สัมภาษณ์แล้วเขียน task ให้ (Interview pattern ของ M2) มีบน Pro, Max, Team, Enterprise ทุกแผนที่จ่ายเงิน แต่ admin ของ Team ปิด Cowork หรือบังคับ approval ได้ ⚠ เมนูเปลี่ยนบ่อย ตรวจหน้าจอจริงสัปดาห์ที่สอนอีกรอบ
