Scheduled task ใน Cowork คืออะไร

  • Prompt ที่ บันทึกไว้ + ตั้งรอบ ให้ Claude ทำเองตามเวลา
  • รอบ: ทุกชั่วโมง · ทุกวัน · ทุกสัปดาห์ · วันทำการ · กดรันเอง
  • สร้างได้ 2 ทาง: Scheduled → New task หรือพิมพ์ /schedule ในแชต Cowork
  • ใช้ Connector, Skill, Plugin ได้เหมือนงานปกติ
  • ตั้ง Approval mode ได้: ให้ถามก่อนทุกครั้ง (เราใช้แบบนี้)
  • ดูประวัติ · แก้ · Pause · Run now เพื่อทดสอบได้ทุกเมื่อ
[1:45] เปิดหน้า Scheduled ใน Claude Desktop ให้ดูของจริง 20 วินาที (SOURCES #1, #2) หน้าต่าง “Set up manually” มีช่อง: ชื่องาน · prompt · approval mode · ความถี่ · model (ไม่บังคับ) · โฟลเดอร์ (ไม่บังคับ) “Create with Claude” = ให้ Claude สัมภาษณ์เราแล้วเขียน task ให้ (เหมือน Interview pattern ของ M2) มีบน Pro, Max, Team, Enterprise ทุกแผนที่จ่ายเงิน แต่ admin ของ Team ปิด Cowork หรือบังคับ approval ได้ ⚠ เมนูเปลี่ยนบ่อย ตรวจหน้าจอจริงสัปดาห์ที่สอนอีกรอบ
