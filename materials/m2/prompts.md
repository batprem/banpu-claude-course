## M2-P01 · Input → Process → Output
```text
Input: [ไฟล์/โฟลเดอร์ที่ใช้ เช่น ไฟล์ทั้งหมดในโฟลเดอร์ input/]
Process: [ทำอะไร ทีละขั้น เช่น รวมเป็นตารางเดียว แล้วเทียบ Budget vs Actual รายไซต์รายปี]
Output: [รูปแบบ + ที่เก็บ + ชื่อไฟล์ เช่น Excel 1 ไฟล์ใน output/ ชื่อ ops_summary.xlsx และสรุป 5 บรรทัดในแชต]
ข้อจำกัด: ใช้เฉพาะข้อมูลในไฟล์ ถ้าข้อมูลไม่พอให้บอก อย่าเดา
```

## M2-P02 · Plan → Approve → Execute (ใส่ต่อท้ายทุกงานที่แตะไฟล์)
```text
ก่อนลงมือ ให้เสนอแผนเป็นรายการขั้นตอน และบอกว่าจะสร้าง/แก้/ย้ายไฟล์ใดบ้าง
ห้ามสร้าง แก้ ย้าย หรือลบไฟล์ใด ๆ จนกว่าฉันจะพิมพ์ว่า "อนุมัติ"
ทำงานเฉพาะในโฟลเดอร์ [Documents/Claude-Workshop/M2] และเขียนผลลัพธ์ลง output/ เท่านั้น
เมื่อทำเสร็จ ให้สรุป log ว่าทำอะไรกับไฟล์ไหนบ้าง
```

## M2-P03 · Use your own words
```text
[คำสั่งงานของคุณ]

ก่อนเริ่ม ให้ทวนเป้าหมายด้วยคำของคุณเอง 3 บรรทัด:
1) งานนี้ทำเพื่อใคร และเขาจะเอาไปใช้ทำอะไร
2) จะใช้ไฟล์/ข้อมูลอะไร
3) ผลลัพธ์หน้าตาเป็นอย่างไร
แล้วหยุดรอให้ฉันยืนยันหรือแก้ไขก่อน
```

## M2-P04 · Interview pattern ("grill me" — แนวคิดจาก Matt Pocock)
```text
ฉันต้องการ [งานที่อยากได้ เช่น สไลด์สรุปผลการดำเนินงาน]
สัมภาษณ์ฉันทีละ 1 คำถาม เพื่อเข้าใจ เป้าหมาย ผู้ฟัง ข้อมูลที่มี ข้อจำกัด และรูปแบบผลลัพธ์
กติกา: ถามครั้งละ 1 ข้อเท่านั้น รอคำตอบก่อนถามข้อถัดไป ถ้าคำตอบกำกวมให้ถามต่อ
เมื่อได้ข้อมูลครบ (ไม่เกิน 8 คำถาม) ให้เขียน brief 1 หน้า: เป้าหมาย · ผู้ฟัง · Input · Output · ข้อห้าม · เกณฑ์ว่าเสร็จ
แล้วรอให้ฉันยืนยัน brief
```

## M2-P05 · Prototype first
```text
ก่อนทำงานฉบับเต็ม ให้ทำตัวอย่าง 3 แบบที่ต่างกันชัดเจน จากเนื้อหาเดียวกัน [เช่น สไลด์หน้า "ภาพรวม Budget vs Actual"]
แบบ 1: Executive — ตัวเลขใหญ่ ข้อความน้อย
แบบ 2: Visual — กราฟเป็นหลัก
แบบ 3: Detailed — ตาราง + bullet สำหรับทีมทำงาน
ตั้งชื่อไฟล์ prototype_1, prototype_2, prototype_3 ใน output/ บอกจุดเด่น/จุดอ่อนของแต่ละแบบ 1 บรรทัด
แล้วรอให้ฉันเลือกก่อนทำฉบับเต็ม
```

## Workshop B · Excel กระจัดกระจาย → Insight

### M2-P06 · Explore + Find files
```text
Input: โฟลเดอร์ input/workshop_b_scattered/ (รวมโฟลเดอร์ย่อย)
Process: สำรวจทุกไฟล์ แล้วทำตาราง inventory: ชื่อไฟล์ · ชนิด · sheet · ไซต์ · ช่วงเวลา · หน่วย · คอลัมน์หลัก · ปัญหาที่เห็น
จากนั้นแนะนำว่าไฟล์ใด "ใช้" และไฟล์ใด "ไม่ใช้" (ไฟล์ซ้ำ เวอร์ชันเก่า นอกช่วงปี 2566–2568) พร้อมเหตุผล
Output: ตาราง inventory ในแชต — ยังไม่ต้องรวมข้อมูล ยังไม่สร้างไฟล์ รอฉันยืนยันรายการไฟล์
```

### M2-P07 · Align schemas
```text
ใช้เฉพาะไฟล์ที่ฉันยืนยันแล้ว
เสนอ schema กลาง: period (YYYY-MM ค.ศ.) · site_code (A–F) · site_name · unit · actual_volume · actual_cost_mthb · budget_volume · budget_cost_mthb
ทำตาราง mapping ต่อไฟล์: คอลัมน์เดิม → คอลัมน์ใหม่ · การแปลงหน่วย (เช่น บาท→ล้านบาท, GWh→MWh) · การแปลงวันที่ (พ.ศ.→ค.ศ.) · การแก้ชื่อไซต์
ห้ามรวมข้อมูลจนกว่าฉันจะอนุมัติ mapping
```

### M2-P08 · Merge + issue log
```text
อนุมัติ mapping แล้ว
รวมข้อมูลเป็นตารางเดียวตาม schema กลาง บันทึกเป็น output/ops_merged.xlsx (sheet: data, issues)
sheet issues: ทุกปัญหาที่เจอ เช่น ข้อมูลหาย ค่าผิดปกติ ไฟล์ที่ตัดทิ้ง — ห้ามเดาเติมค่าที่หายไป
ตรวจผล: จำนวนแถวต่อไซต์ต่อปีควรเป็น 12 ถ้าไม่ครบให้บอกว่าขาดเดือนไหน
```

### M2-P09 · Analyse + Insight / Dashboard
```text
Input: output/ops_merged.xlsx
Process: เทียบ Budget vs Actual รายไซต์รายปี (ปริมาณ ต้นทุน ต้นทุนต่อหน่วย) หา 3–5 insight ที่ผู้บริหารควรรู้ พร้อมตัวเลขอ้างอิงและเดือนที่เกิด
Output:
1) output/ops_insight.xlsx (sheet สรุป + กราฟ)
2) Artifact dashboard 1 หน้า (การ์ดตัวเลข + กราฟ Budget vs Actual + ตาราง insight) ที่มีปุ่ม Export PDF
3) สรุป insight 5 บรรทัดในแชต (จะใช้เป็น input ของ Workshop A)
ทุกตัวเลขต้องมาจากไฟล์ ถ้าไม่แน่ใจให้ระบุ
```

## Demo · จัดโครงสร้างโฟลเดอร์ (~1,500 ไฟล์)

### M2-P16 · วิเคราะห์ + เสนอโครงสร้าง (Plan only)
```text
Input: โฟลเดอร์ [messy_folder_copy] (สำเนา ห้ามแตะต้นฉบับ)
Process:
1) ทำ inventory สรุป: จำนวนไฟล์ตามปี (พ.ศ.) · ชนิดไฟล์ · หัวข้อ/ไซต์ที่เดาได้จากชื่อ · ไฟล์ที่น่าจะซ้ำ (ชื่อคล้าย/ขนาดเท่ากัน)
2) เสนอโครงสร้างโฟลเดอร์ใหม่ 2 ทางเลือก (เช่น ปี → ประเภท vs ไซต์ → ปี) พร้อมข้อดีข้อเสีย
3) เสนอกฎตั้งชื่อไฟล์ เช่น YYYY-MM_ไซต์_หัวข้อ_vN
4) ทำไฟล์ output/move_plan.csv: path เดิม · path ใหม่ · ชื่อใหม่ · เหตุผล · ความมั่นใจ (สูง/กลาง/ต่ำ)
Output: สรุปในแชต + move_plan.csv
ห้ามย้าย เปลี่ยนชื่อ หรือลบไฟล์ใด ๆ — ไฟล์ที่ไม่แน่ใจให้จัดไป _ตรวจด้วยคน/ ในแผน ไม่ลบ
```

## M2-P20 · Project instructions (สำหรับงานที่ทำซ้ำทุกเดือน)
```text
คุณคือผู้ช่วยทำรายงานผลการดำเนินงานรายเดือนของทีม [ชื่อทีม]
- ใช้เอกสารใน Project นี้เป็นแหล่งอ้างอิงหลัก (template, คำศัพท์, รหัสไซต์)
- ทุกตัวเลขต้องระบุแหล่ง (ไฟล์/sheet) ถ้าไม่มีข้อมูลให้บอก อย่าเดา
- หน่วยมาตรฐาน: ตัน, MWh, ล้านบาท · ปีใช้ พ.ศ. ในหัวข้อ และ ค.ศ. ในข้อมูล
- ก่อนสร้างไฟล์ ให้ทวนเป้าหมายและเสนอแผนก่อนเสมอ (Plan → Approve → Execute)
- ห้ามรับหรือประมวลผลข้อมูลสีแดงตาม Data Traffic Light (ข้อมูลส่วนบุคคล ข้อมูลการเงินที่ยังไม่เปิดเผย)
```
