# Spec · M2 Prototype Gallery (individual style pick)

- **Purpose:** practise Prompt Pattern 3 *Prototype first*: compare 3 slide styles built from the same synthetic data before Claude builds the full deck (Workshop A).
- **Users:** each learner on their own; no group work, no class vote, no presenting.
- **Content:** 3 sample slides — 1 Executive · 2 Visual · 3 Detailed (Budget vs Actual 2568, synthetic sites) with pros/cons.
- **Interactions:** "เลือกแบบนี้" marks one style as mine (✓ แบบที่ฉันเลือก); a 1-line reason (≤140 chars) is saved; a box shows "ฉันเลือก … · เหตุผล …".
- **Storage:** this browser only (`localStorage`, wrapped in try/catch); nothing is shared or aggregated.
- **Export PDF:** prints the 3 styles plus my choice and reason (the textarea is hidden in the PDF).
- **AI calls:** none.
