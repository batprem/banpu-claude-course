# Spec · M2 Prompt Playground (Before / After)

- **Purpose:** show, in 5 minutes, why Input → Process → Output and the 3 Prompt Patterns beat a one-line prompt.
- **Users:** learners during the lecture-to-workshop transition; trainer for a quick demo.
- **Content:** 6 cases — สรุปไฟล์ในโฟลเดอร์ · ย้ายไฟล์ (Plan → Approve → Execute) · ทำสไลด์ · งานที่บริบทยังไม่ชัด (Interview pattern) · เลือกสไตล์ก่อนทำจริง (Prototype first) · PDF 320 หน้า (real-volume limit). Each shows a weak prompt, learners guess what's missing, then **reveal** the improved prompt with annotations.
- **Builder:** "ลองประกอบ prompt ของคุณ" form (Input / Process / Output / checkpoint) that assembles a copy-ready prompt and gives a simple completeness score.
- **Engagement mechanic:** guess-then-reveal, score for the builder.
- **Data:** synthetic site names only; state in `localStorage`.
- **Export PDF:** prints all before/after pairs revealed plus the learner's built prompt.
- **AI calls:** none.
