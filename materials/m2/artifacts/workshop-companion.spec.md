# Spec · M2 Workshop Companion

- **Purpose:** keep every learner on the same step during the 30-minute M2 workshop (Workshop B → Workshop A → folder plan).
- **Users:** learners (open on a second screen or as an Artifact); trainer projects it to pace the room.
- **Content:** 6 tabs = the 6 pages of `workshop.md` (เตรียมโฟลเดอร์ · Workshop B ×2 · Workshop A ×2 · ลองเอง Plan only). Each tab: เป้าหมาย, time box, colour chips (คน / AI / Data), copy-ready prompts (IDs from `prompts.md`), ✅ HITL checkpoint checklist.
- **Interactions:** tab navigation, one-click **Copy prompt**, tick checklist items, progress bar across all steps, per-step timer.
- **Engagement mechanic:** visible progress %, ✓ on completed tabs, checkpoint ticks before moving on (reinforces Plan → Approve → Execute).
- **Data:** none beyond the prompts; progress saved in `localStorage` (this browser only, wrapped in try/catch).
- **Export PDF:** button + print CSS prints all 6 steps expanded with checklists (learners keep it as a handout).
- **AI calls:** none (no Team-plan usage).
