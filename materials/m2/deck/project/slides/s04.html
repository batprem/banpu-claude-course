รู้แล้วว่าจะให้ไฟล์แบบไหน ต่อไปคือสั่งงานยังไงให้ได้ผลครับ Prompt ที่ดีตอบสามคำถาม หนึ่ง Input เอาอะไรเข้า ไฟล์หรือโฟลเดอร์ไหน ข้อมูลอะไร สอง Process ให้ Claude ทำอะไร ทีละขั้น สาม Output ได้อะไรออกมา รูปแบบไหน เก็บที่ไหน ชื่อไฟล์อะไร ข้อผิดพลาดที่เจอบ่อยที่สุดคือ บอกแค่ Process ครับ เช่น วิเคราะห์ให้หน่อย แล้ว Claude ก็ต้องเดา input และ output เอง ลองดูตัวอย่างด้านล่างครับ Input คือไฟล์ทั้งหมดในโฟลเดอร์ input รายงานผลผลิต 6 ไซต์ ปี 2566 ถึง 2568 Process คือรวมเป็นตารางเดียว เทียบ Budget vs Actual รายไซต์รายปี Output คือ Excel หนึ่งไฟล์ในโฟลเดอร์ output ชื่อ ops_summary.xlsx พร้อมสรุปห้าบรรทัด แล้วสังเกตเส้นประสีส้มครับ หลังได้ผล คนตรวจว่าตรงเป้าหมายไหม ถ้าไม่ตรงก็ย้อนกลับไปปรับ prompt นี่คือ Human-in-the-Loop ที่เล็กที่สุด ---------- [3:00–4:30] ประมาณ 1 นาทีครึ่ง Cue: ชี้เส้นประย้อนกลับ = คนตรวจผลแล้วปรับ prompt (HITL ที่เล็กที่สุด) ข้อผิดพลาดที่เห็นบ่อย: บอกแค่ Process ("วิเคราะห์ให้หน่อย") → Claude เดา input/output เอง ถ้ามีเวลา: เปิด Prompt Playground ตัวอย่างที่ 1 (before/after)
