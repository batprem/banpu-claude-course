(1:30–3:00) ตารางเทียบ (พูดประกอบ): - เหมาะกับ: Upload ในแชต = ถามครั้งเดียว 1–5 ไฟล์ · Project = งานซ้ำ ใช้เอกสารอ้างอิงเดิม · Cowork + โฟลเดอร์ = ไฟล์เยอะ ต้องสร้าง/ย้ายไฟล์ - Claude ทำได้: Upload = อ่าน + ตอบ · Project = อ่าน + คำสั่งประจำ · Cowork = อ่าน เขียน สร้างไฟล์ ย้ายไฟล์ - ระวัง: Upload = ไฟล์ใหญ่อัปโหลดไม่ผ่าน · Project = ความรู้ล้าสมัยถ้าไม่อัปเดต · Cowork = ให้สิทธิ์เฉพาะโฟลเดอร์สำเนา ตัวอย่างบ้านปูสมมติ: - Upload: "สรุป PDF ใบเสนอราคา supplier ฉบับนี้" → ครั้งเดียว - Project: "รายงานประจำเดือนของทีม" ที่ต้องใช้ template + คำศัพท์เดิมทุกเดือน - Cowork folder: "รวม Excel 13 ไฟล์จาก 6 ไซต์ แล้วทำ dashboard" → ต้องอ่านหลายไฟล์และสร้างไฟล์ใหม่ กฎ: ให้ Cowork เข้าถึงโฟลเดอร์ทำงานเฉพาะงาน (เช่น Documents/Claude-Workshop/M2) ไม่ใช่ทั้งไดรฟ์ — และใช้สำเนา (copy-before-write) Connector ไป SharePoint/Outlook จะเรียนใน M3
