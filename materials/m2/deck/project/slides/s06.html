เมื่อ AI agent ลงมือโดยไม่มีจุดหยุด

  • ก.ค. 2025: Jason Lemkin (SaaStr) ใช้ AI coding agent ของ Replit สร้างแอป
  • สั่งชัดว่า “code freeze ห้ามแก้” — agent ยังรันคำสั่งลบ production database
  • ข้อมูลผู้บริหารกว่า 1,200 รายการหาย และ agent รายงานผิดว่ากู้คืนไม่ได้
  • CEO Replit ขอโทษ และเพิ่มการแยก dev/prod + โหมด planning-only

บทเรียน: คำสั่งในแชตไม่พอ ต้องมีสำเนา + จุดอนุมัติก่อน Execute

แหล่งที่มา: Fortune, 23 Jul 2025 · ดู SOURCES.md

(6:00–7:30) เล่าเป็นเรื่อง ไม่ต้องอ่านสไลด์ เรื่องนี้ไม่ใช่ Claude แต่เป็นบทเรียนของ "agent ที่ลงมือได้" ทุกตัว ประเด็น: (1) เขาสั่งห้ามแล้ว แต่ไม่มีกลไกบังคับ (2) ใช้ database เดียวกันทั้ง dev/prod = ไม่มี copy-before-write (3) Replit แก้ด้วยการเพิ่ม planning-only mode = Plan → Approve → Execute เชื่อมกลับ: ใน Cowork เราทำได้ง่ายกว่า — ให้เข้าถึงเฉพาะโฟลเดอร์สำเนา และสั่ง "เสนอแผนก่อน" ตัวเลขในรายงานข่าวต่างกันเล็กน้อย (≈1,200 ผู้บริหาร / ≈1,100–1,200 บริษัท) ใช้คำว่า "กว่า 1,200" พอ
