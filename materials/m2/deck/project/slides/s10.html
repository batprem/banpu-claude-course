Pattern 3 · Prototype first

  • ขอ สไลด์ตัวอย่าง 3 สไตล์ (หน้าเดียวกัน เนื้อหาเดียวกัน)
  • เลือก 1 แบบ หรือผสม → แล้วค่อยสร้างทั้ง deck
  • ถูกกว่าแก้ deck 15 หน้าทีหลัง ทั้งเวลาและ usage
Pattern ที่สาม Prototype first ครับ ก่อนให้ Claude สร้าง deck ทั้งชุด เราขอสไลด์ตัวอย่างสามสไตล์ก่อน เป็นหน้าเดียวกัน เนื้อหาเดียวกัน เช่น แบบแรก Executive ตัวเลขใหญ่ ข้อความน้อย แบบที่สอง Visual เน้นกราฟเป็นหลัก แบบที่สาม Detailed มีตารางกับ bullet สำหรับทีมทำงาน เราเลือกหนึ่งแบบ หรือจะผสมก็ได้ แล้วค่อยสร้างทั้ง deck ทำไมคุ้มครับ เพราะถูกกว่าไปแก้ deck 15 หน้าทีหลังเยอะ ทั้งเวลาและ usage และไม่ได้ใช้แค่กับสไลด์นะครับ ใช้ได้กับรูปแบบรายงาน layout ของ dashboard หรือแม้แต่โทนอีเมล ใน Workshop A เราจะได้ลองจริง โดยใช้ Prototype Gallery Artifact ให้แต่ละคนเลือกสไตล์ของตัวเองครับ ---------- [10:15–11:00] ประมาณ 45 วินาที สามสไตล์ตัวอย่าง: (1) Executive — ตัวเลขใหญ่ ข้อความน้อย (2) Visual — กราฟเป็นหลัก (3) Detailed — ตาราง + bullet สำหรับทีมทำงาน ใช้ได้กับทุกงาน ไม่ใช่แค่สไลด์: รูปแบบรายงาน, layout dashboard, โทนอีเมล ปูทาง Workshop A: Prototype Gallery Artifact แต่ละคนเลือกสไตล์ของตัวเอง (ไม่มีโหวตรวม ไม่ต้องนำเสนอ)
