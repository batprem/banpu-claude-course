40 นาทีนี้เราจะได้อะไร

  • เห็นสายพาน Document Factory: Multiple Sources → Process → Report
  • รวม 5 แหล่ง (ภายใน + สาธารณะ) เป็น Monthly Operations Report
  • ใช้ Artifact เป็น output layer: Dashboard · App · Prototype · Diagram
  • เลือกได้ว่าเมื่อไรใช้ Word / Excel / PDF / PPT แทน
  • แก้ปัญหา รายงานใหญ่เกินแนบอีเมล ได้ 3 วิธี
40 นาทีนี้เราจะได้อะไรกลับไปบ้างครับ ข้อแรก เราจะเห็นสายพานที่เรียกว่า Document Factory คือเอาข้อมูลจากหลายแหล่ง ผ่านการ Process แล้วออกมาเป็น Report ข้อสอง เราจะรวมข้อมูล 5 แหล่ง ทั้งข้อมูลภายในและข้อมูลสาธารณะ ให้เป็น Monthly Operations Report ฉบับเดียว ข้อสาม เราจะใช้ Artifact เป็น output layer ทำได้ทั้ง Dashboard, App, Prototype และ Diagram ข้อสี่ เราจะเลือกเป็นว่าเมื่อไรควรใช้ Word, Excel, PDF หรือ PowerPoint แทน และข้อสุดท้าย ถ้ารายงานใหญ่จนแนบอีเมลไม่ได้ เรามี 3 วิธีแก้ครับ สรุปง่าย ๆ วันนี้ทุกคนจะได้ของกลับบ้าน 3 อย่าง ไฟล์ Word หรือ PPTX หนึ่งฉบับ Artifact Dashboard หนึ่งตัว และวิธีส่งรายงานใหญ่ แล้วบอกไว้ก่อนเลยนะครับ รายงานที่เราทำวันนี้ เราจะเอาไปตั้งเป็นงานอัตโนมัติใน M6 ช่วงบ่ายสองโมงกว่าครับ ---------- [0:45] อ่านเร็ว ไม่ต้องอธิบายลึกแต่ละข้อ ผลงานที่ได้กลับบ้าน: ไฟล์ Word/PPTX 1 ฉบับ + Artifact Dashboard 1 ตัว + วิธีส่งรายงานใหญ่ บอกล่วงหน้า: รายงานที่ทำวันนี้จะถูกตั้งเป็นงานอัตโนมัติ (Schedule/Distribution) ใน M6 บ่ายสองโมงกว่า
